#Personal Portfolio Website

#Repository ini berisi tugas mata kuliah PWEB berupa hasil slicing halaman portofolio pribadi dan memakai referensi dari komunitas di figma.
Halaman web ini dibangun secara responsif serta dilengkapi interaktivitas menggunakan JavaScript, HTML, dan CSS.


📝 Penjelasan Singkat Halaman

Halaman web portofolio ini terdiri dari beberapa komponen utama:

Header & Navigation: ada logo identitas nama.

Menu navigasi scroll.

Tombol interaktif Ganti Background untuk mengubah wallpaper website.

Home Section: Foto profil dan perkenalan singkat.

Link langsung ke medsos

Project Showcase

Contact & Footer: Informasi email dan tombol Get In Touch yang langsung membuka compose draft Gmail baru.

⚙️ Fitur Interaktif (adadeh.js)

Dynamic Background Switcher: Mengubah background secara melingkar dari daftar gambar yang tersimpan di array bgList.

Active Navigation on Scroll: Mendeteksi posisi scroll layar dan menandai link navbar yang aktif

Direct Mailto Trigger: Membuka web gmail

🛠️ Teknologi yang Digunakan

HTML5 

CSS

JavaScript

Font Awesome 6.5.2 & Devicon
